# One Go import path per line. The dead-code tool reads this list, runs
# golang.org/x/tools/cmd/deadcode over the whole module, and reports every
# unreachable production declaration in these packages. A symbol key is
# package-qualified, so an entry names "<import path>.<Symbol>" or
# "<import path>.<ReceiverType>.<name>".
#
# The list is derived from the tree by this rule: every package under
# opl-cloud/services/... and every package under opl-cloud/apps/console-bff/...,
# except a cmd/ entry-point package, which is a program root rather than a
# subject, and except opl-cloud/packages/contracts/go/..., which is the
# generated contract client rather than an owner implementation.
#
# The tool refuses to run when this list no longer equals that derived set, so
# a package cannot leave the boundary without this file being updated.
