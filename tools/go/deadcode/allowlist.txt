# Allowlisted unreferenced implementations in the Cloud production packages
# declared by tools/go/deadcode/targets.txt.
#
# The dead-code check reports every production declaration that no source in
# the declared packages can reach. This file is the explicit, reviewed list of
# the declarations that are allowed to stay unreachable. Every entry carries the
# reason it cannot simply be deleted.
#
# Adding an entry is a deliberate act that needs the same review as deleting
# the implementation would. Removing an entry is the point of the check.
#
# Format: one symbol key per line, followed by a "#" reason. The key is
# package-qualified, because a bare name can collide across packages: a
# package-level symbol is "<import path>.<Symbol>" and a method is
# "<import path>.<ReceiverType>.<name>".
#
# Every entry below is a pre-existing finding that this boundary now covers.
# None of them was introduced by the boundary's relocation.
